# 🎓 EduPal — AI Chatbot Edukasi

EduPal adalah chatbot edukasi berbasis AI yang ramah dan menyenangkan untuk semua kalangan.

## ✨ Fitur
- Tanya jawab pelajaran sekolah (Matematika, IPA, Sejarah, dll)
- Bahasa Indonesia yang santai dan mudah dipahami
- UI modern dengan efek glassmorphism
- Typing animation seperti ChatGPT

## 🛠️ Tech Stack
- Streamlit (Frontend)
- Groq API (LLM Llama 3.3 70B)
- Python

## 🚀 Cara Menjalankan

```bash
pip install -r requirements.txt
streamlit run app.py
