# 🎓 EduPal — AI Chatbot Edukasi

EduPal adalah chatbot edukasi berbasis AI yang ramah dan menyenangkan untuk semua kalangan.

## ✨ Fitur
- Tanya jawab pelajaran sekolah (Matematika, IPA, Sejarah, dll)
- Bahasa Indonesia yang santai dan mudah dipahami
- UI modern dengan efek glassmorphism
- Typing animation seperti ChatGPT
- **GRATIS** menggunakan Groq API

## 🛠️ Tech Stack
- **Frontend:** Streamlit
- **AI Model:** Llama 3.3 70B (via Groq API)
- **Bahasa:** Python

## 🚀 Cara Menjalankan di Lokal

```bash
# Clone repository
git clone https://github.com/herihendrawan86/edupal-chatbot.git

# Masuk ke folder
cd edupal-chatbot

# Install dependencies
pip install -r requirements.txt

# Jalankan app
streamlit run app.py
